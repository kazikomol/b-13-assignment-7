## 📌 Project Overview


**KenKeeper** is a personal relationship management project that helps you stay meaningfully connected with your friends — tracking interactions, milestones, and the health of your friendships over time.

---

## 🛠 Main Technologies Used

* **Frontend Framework:** React.js
* **Build Tool:** Vite
* **Styling & UI Components:** Tailwind CSS, DaisyUI
* **Routing:** React Router DOM
* **Icons & UI Enhancements:** Lucide React / React Icons
* **Deployment:** Vercel

---

## ✨ Key Features

* **📱 Fully Responsive Design:** Optimized for mobile, tablet, and desktop devices.
* **🦁 Category Filtering:** Easily browse and filter animals by categories and species.
* **🐾 Adoption & Care Requests:** Seamless system for submitting adoption inquiries and care requests.
* **🔐 User Authentication:** Secure authentication for user registration and login.
* **⚡ Dynamic UX & Fast Performance:** Smooth navigation and lightweight rendering for fast load times.

---


## 📦 Key Dependencies & Libraries

- `react` & `react-dom` — Core UI framework
- `react-router-dom` — Routing and page layout architecture
- `tailwindcss` — Utility-first CSS framework
- `daisyui` — Component library for Tailwind CSS
- `react-icons` — Icon sets for UI controls
- `react-toastify` — Dynamic visual alerts and feedback
